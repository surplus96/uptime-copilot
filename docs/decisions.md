`uptime-update-plan.md`의 H2(교차 검토 운영)에 따라, 🔶 교차 검토 체크포인트(CP-U1, CP-U2, CP-U3 등)의
결과를 여기에 기록한다. 형식: 날짜 · 체크포인트 ID · 지적 사항 · 조치 · 미해결 항목.

각 항목은 아래 형식으로 추가한다:

```
## YYYY-MM-DD — [체크포인트 ID]

**지적 사항**
- ...

**조치**
- ...

**미해결 항목**
- ...
```

## 2026-09-23 — 3-1 데이터 탐색: 계획서 5-2 피처 창 변경

**지적 사항**
- `uptime-update-plan.md` 5-2의 피처 표는 오류-횟수 피처를 "최근 24h"로만 명시했으나,
  실측(`docs/model_exploration.md` 3절) 결과 선행 오류는 고장 24~36시간 전 구간에
  98% 몰려 있고, 고장 직전 24시간 안에는 8.5%만 존재 — 24h 창만 쓰면 가장 강한
  신호를 예측 시점 대부분에서 놓친다.

**조치**
- 오류-횟수 피처를 24h 단일 창에서 24h + 48h 이중 창으로 확장하기로 사용자 승인받음
  (2026-09-23). 라벨 정의(향후 24h 내 고장)는 변경 없음, 피처 창만 확장.
- 3-2(피처 파이프라인) 구현 시 이 결정을 반영한다.

**미해결 항목**
- 없음 (설계 단계 결정, 구현은 3-2에서)
