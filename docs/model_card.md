# 부품별 고장 위험 모델

## 예측 대상과 입력

LightGBM 이진 분류기 4개가 설비별로 향후 24시간 내 comp1~4의 고장 위험 점수를 산출한다. 각 샘플의 기준 시각 T에 대해 (T, T+24시간]에 해당 부품의 고장이 기록되면 양성이다. 판정 임계값은 0.5이며 점수의 확률 보정은 수행하지 않는다.

입력은 4개 센서의 3·24시간 이동평균과 표준편차, 오류 유형별 24·48시간 발생 횟수, 부품별 정비 후 경과시간, 설비 모델과 사용연수다. 3시간 간격으로 표본을 만들며 관측 시작의 불완전한 오류 창과 관측 끝의 불완전한 라벨 창을 제외한다.

## 학습과 평가

2015년 1~8월을 학습, 9~10월을 검증, 11~12월을 테스트로 사용한다. 부품별 모델은 트리 200개, 학습률 0.05, 최대 잎 수 15개와 클래스 불균형 가중치를 사용한다. 비교 기준선은 학습 구간에서 구한 설비별 센서 평균과 표준편차로 계산한 3σ 경보다.

## 재현과 적용 범위

저장소 루트에서 [README의 모델 학습 명령](../README_KOR.md)을 실행하면 모델은 백엔드의 `store/ml_models/`, 평가표는 `store/ml_features/eval_results.csv`에 생성된다. 수치는 합성 Azure PdM의 시간 분할 결과다. 실제 설비의 센서 분포, 교체 주기와 오류 코드가 달라질 때의 성능은 검증되지 않았다.
