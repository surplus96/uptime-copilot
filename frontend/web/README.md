# React 운영 콘솔

React와 TypeScript로 구현한 설비 운영 화면이다. Vite 개발 서버와 배포용 Nginx는 브라우저의 `/api/` 요청을 FastAPI로 전달한다.

## 개발 서버

[프로젝트 실행 가이드](../../README_KOR.md)에 따라 백엔드를 준비한 뒤 저장소 루트에서 실행한다. 프런트엔드 CI는 Node.js 24를 사용한다.

```sh
cd frontend/web
npm ci
npm run dev
```

기본 주소는 http://127.0.0.1:5173 이며 API 대상은 http://127.0.0.1:8000 이다. 다른 백엔드에 연결하려면 `BACKEND_URL=http://127.0.0.1:8001 npm run dev`처럼 Vite 서버에 값을 지정한다.

## 화면과 상태 복구

- 설비 탐색은 센서별 구간 평균, 최소·최대, 표본 수와 관측 지연을 표시한다. 감지 이벤트 화면은 서버에서 검색·필터·페이지 처리를 수행한다.
- 진단 화면은 URL의 thread ID로 서버 체크포인트를 읽는다. 승인 대기함에서 기존 진단을 다시 열 수 있다. 저장된 진단 근거와 주기적으로 갱신하는 설비 상태는 각자의 기준 시각을 표시한다.
- 승인 요청이 시간 초과되면 상태를 다시 조회한 후 재시도한다. 구조화된 작업지시서가 없는 기존 체크포인트는 저장된 원문을 표시한다.
- 재고 화면에서는 부품별 합성 재고와 30·90일 수요 추정치를 비교한다. 단일 설비 시뮬레이션 조작과 상태 값은 [UI 계약](../../docs/design/UI_API_CONTRACT.md)에 정리했다.

## 테스트와 배포 빌드

```sh
npm test
npm run build
```

`npm run preview`로 정적 빌드를 확인할 수 있다. API 연동은 개발 서버 또는 Compose를 사용한다. Compose의 `web` 서비스는 Nginx로 빌드 결과를 제공하며 기본 호스트 포트는 3001이다. 실행 시 `UPTIME_WEB_PORT`로 변경할 수 있다.
