# 설비 부품별 정비 매뉴얼
(데이터의 텔레메트리 신호 구성에 근거해 원심펌프로 가정한 가상 시나리오)

## comp1: 전동기(모터) 구동부 - 전압 계통과 관련된 핵심 부품
대표 증상: 전압 이상 경고(error1), 모터 과열, 전류 불안정
표준 점검 절차:
  1. 전원 공급 상태 및 공급 전압 안정성 확인
  2. 모터 권선 절연저항 측정
  3. 모터 베어링 윤활 상태 확인
  4. 열화상 카메라로 모터 과열 부위 점검
실제 이력 기준: model1 기종에서 설비 1대당 평균 2.062회로 가장 잦게 발생함.

## comp2: 회전자/베어링 - 회전속도 이상과 관련된 부품
대표 증상: 회전속도 이상 경고(error2), 베어링 마모음, 축 흔들림
표준 점검 절차:
  1. 회전속도 로그에서 이상 패턴 확인
  2. 베어링 마모 상태 육안 및 진동 점검
  3. 축 정렬(shaft alignment) 상태 확인
  4. 윤활유/그리스 상태 및 주기 점검
실제 이력 기준: model1 기종에서 설비 1대당 평균 2.875회로 가장 잦게 발생함.

## comp3: 유압/공압 계통 부품 - 압력 이상과 관련
대표 증상: 압력 이상 경고(error3), 기계식 씰 누설, 캐비테이션 소음
표준 점검 절차:
  1. 흡입/토출 압력 게이지 수치 확인
  2. 기계식 씰 누설 여부 육안 점검
  3. 캐비테이션 징후(이상 소음·기포) 확인
  4. 배관 막힘 및 밸브 개폐 상태 점검
실제 이력 기준: model1 기종에서 설비 1대당 평균 4.25회로 가장 잦게 발생함.

# 사전 경보(텔레메트리 이상탐지) 안내

사전 경보(텔레메트리 이상탐지)는 error1~5 같은 이산적 오류 코드와는 다른 개념이다.
아직 오류 코드가 발생하지 않았어도, 설비 자신의 과거 평균 대비 센서값(전압/회전속도/압력/진동)이
통계적으로 크게 벗어나면(Z-score 기준) 이를 "사전 경보"로 별도 분류한다.
이는 실제 오류 이벤트가 아니라 예방 점검을 권장하는 조기 신호이며, 특정 error 코드로 단정해서
부르면 안 된다. 해당 신호와 관련된 부품의 표준 점검 절차를 그대로 적용하되, 긴급도는
'주의' 수준(예방 점검 권장, 즉각 가동 중지 불필요)으로 다룬다.


- volt 신호 이상 -> comp1(전동기(모터) 구동부 - 전압 계통과 관련된 핵심 부품) 관련 표준 절차 적용, 긴급도는 '주의'
- rotate 신호 이상 -> comp2(회전자/베어링 - 회전속도 이상과 관련된 부품) 관련 표준 절차 적용, 긴급도는 '주의'
- pressure 신호 이상 -> comp3(유압/공압 계통 부품 - 압력 이상과 관련) 관련 표준 절차 적용, 긴급도는 '주의'
- vibration 신호 이상 -> comp4(진동 저감 장치 - 기계적 진동/불균형과 관련) 관련 표준 절차 적용, 긴급도는 '주의'

## comp4: 진동 저감 장치 - 기계적 진동/불균형과 관련
대표 증상: 진동 이상 경고(error4), 임펠러 불균형에 따른 과진동
표준 점검 절차:
  1. 진동 센서 로그의 Z-score 이상 여부 확인
  2. 임펠러 불균형·마모 상태 점검
  3. 마운트/댐퍼 열화 여부 확인
  4. 체결 볼트 토크 상태 점검
실제 이력 기준: model1 기종에서 설비 1대당 평균 2.625회로 가장 잦게 발생함.
